# CitySense - AI-Powered City Intelligence Agent 🌆

CitySense is an AI-powered city assistant that provides real-time weather updates and the latest city news using an LLM-based agent. Built with LangChain and Groq, it intelligently selects tools to answer user queries and incorporates human approval before executing tool calls.

## ✨ Features

- 🌦️ **Weather Updates:** Get current weather conditions and temperature for any supported city.
- 📰 **Latest News:** Retrieve recent city-related news with source links.
- 🤖 **AI Agent:** Uses LLM-powered tool calling to understand queries and select appropriate tools.
- 🛡️ **Human-in-the-Loop:** Requires user approval before executing tool calls.
- 💬 **Interactive Interface:** Chat with the agent through a Streamlit web application.

## 🛠️ Tech Stack

- **Python**
- **LangChain** — Agent creation and tool orchestration
- **Groq (Qwen)** — LLM inference
- **Streamlit** — Web interface
- **OpenWeatherMap API** — Weather data
- **Tavily Search API** — News search
